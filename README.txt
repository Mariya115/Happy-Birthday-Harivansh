MOMO — A LITTLE BIRTHDAY SCRAPBOOK

Run locally: open index.html in a modern browser. For the most reliable local media behavior, open PowerShell in this folder and run: py -m http.server 8000 then visit http://localhost:8000.

Included now: 5 solo photos in images/momo/, 6 couple photos in images/us/, and 7 candid photos in images/moments/. The supplied MP3 is copied to audio/birthday-song.mp3 and starts after the gift click (browser playback rules permitting). The site also works if music is unavailable.

Add photos: copy image files into the appropriate folder and add entries to media.js. Each item uses {src:'images/momo/your-file.jpg', caption:'your caption ♡'}. Use the momo, us, or moments array. Paths are relative to this folder. Photos remain individually displayed with aspect ratio preserved. Videos can be added in videos/; the current galleries are photo galleries and need a video player addition to display video files.

Controls: gift opens the celebration; answer all three questions; choose a gallery card; previous/next buttons, keyboard arrows, Escape, and mobile swipe navigate/close the gallery. Edit the love letter directly; changes save in this browser. Music button pauses/resumes. The ending has a replay button.

Note: only the 18 image attachments included with the current request were accessible here (5 solo, 6 couple, 7 moments). If you intended additional photos beyond these, copy them into the project and add them to media.js.
